등불지기를 만든 첫날 기록이에요. 하루 전날(11월 17일) 기획을 정하고, 18일 새벽에 Unity 프로젝트를 세워 밤까지 만들었어요.

## 1. 무엇을 만들지 정하기 (11월 17일)

처음 정한 큰 줄기는 이래요.

- **장르**: 탑다운 2D 로그라이트 액션. 적은 그림으로도 여러 번 다시 할 거리를 만들 수 있어서요.
- **조작**: 이동 하나, 공격은 자동. 이동만으로 조작이 끝나니 휴대폰 터치에 잘 맞아요.
- **특징**: **등불 시야**. 던전이 어둡고 등불이 비추는 곳만 보여요. 그리고 자동 공격도 **등불 빛 안의 적만** 노리게 해서, 등불을 게임 규칙의 한가운데에 두었어요.
- **플랫폼**: PC와 휴대폰 브라우저. 링크 하나로 공유하고 폰에서도 바로 하게요.
- **그림**: 16비트 픽셀아트, 폰트는 픽셀 한글 폰트 Galmuri.
- **성장**: 한 판 안에서는 업그레이드 셋 중 하나를 고르고, 죽어도 남는 영혼 조각으로 새 무기와 업그레이드를 해금.

처음엔 구역 셋·보스 셋·무기 여덟 개로 크게 잡았다가, 검토해 보니 첫 버전으로는 너무 커서 **구역 둘·보스 둘·무기 다섯·업그레이드 열다섯**으로 줄였어요.

## 2. 회색 상자

그림 없이 네모와 동그라미로 먼저 움직이게 만들었어요.

1. 타이틀 화면, 게임 상태 전환, 데이터 불러오기
2. 방 안에서 이동, 등불 빛, 휴대폰 조이스틱
3. 투척 단검과 첫 적 해골 병사, 몰려오는 웨이브
4. 성능 측정 모드 — 휴대폰에서 버틸 수 있는지 먼저 확인

## 3. 한 판의 흐름

방 다섯 개를 차례로 지나고 문으로 넘어가는 흐름을 만들었어요. 벽에 막힌 적이 돌아서 오게 하고, 업그레이드 카드를 고르는 화면, 체력·일시정지·결과 화면까지 붙였어요. 휴대폰을 세로로 들면 "가로로 돌려 주세요" 안내가 나오게 했어요.

그리고 첫 보스 **해골왕**. 졸개를 부르고, 원형 탄막을 뿌리고, 체력이 줄면 돌진해요. 여기까지 직접 1구역을 끝까지 해 보고 난이도는 "적당함"으로 확인했어요.

## 4. 성장과 두 번째 구역

- 영혼 조각이 떨어지고 줍고, 세이브에 남게
- 해금 화면: 업그레이드 7개와 무기 4개(회전 낫·성수병·번개 지팡이·불꽃 등잔)를 조각으로 열기
- 화상 상태이상
- 2구역 독버섯 동굴: 독 슬라임, 거미, 그리고 두 번째 보스 **거미 여왕** — 부채꼴로 거미줄을 쏘고, 새끼 거미를 부르고, 2페이즈에는 등불 빛을 줄여요
- 거미 여왕을 잡으면 엔딩 문장과 클리어 결과

## 5. 첫 그림

회색 상자에 그림을 입혔어요. 처음엔 이미지 생성 서비스로 그리다가, 같은 날 방식을 바꿔 **Claude가 픽셀을 한 칸씩 직접 찍어** 그렸어요. 주인공 걷기(위·아래·옆), 지하묘지와 동굴 타일, 1구역 적 넷의 대기·걷기, 해골왕, 투사체와 줍는 물건까지요.

첫날이 끝났을 때, 두 구역을 지나 보스 둘을 잡고 엔딩까지 가는 게임이 회색 상자 반, 그림 반으로 돌아갔어요.
