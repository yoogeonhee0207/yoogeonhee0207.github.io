이 파일은 글쓰기 예시예요. `draft: true` 라서 사이트에는 보이지 않아요.

새 글을 쓰려면 이 파일을 복사해서 `src/posts/글-주소.md` 로 저장하고,
위쪽 정보(title, description, date)를 고친 뒤 `draft: true` 줄을 지우면 돼요.
파일 이름이 글 주소가 됩니다. (예: `first-boss.md` → `/blog/first-boss/`)

## 소제목은 이렇게

본문은 마크다운으로 써요. **굵게**, [링크](https://example.com), `코드`도 쓸 수 있어요.

```csharp
void Update() {
    transform.position += velocity * Time.deltaTime;
}
```
